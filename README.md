## Требования

- **Python 3.6 или новее**  
  Проверить версию:

  ```bash
  python3 --version
  ```

  или в Windows:

  ```cmd
  python --version
  ```

- **Git** — для клонирования репозитория.

## Клонирование репозитория

Выполните в терминале (Linux/macOS) или в командной строке/PowerShell (Windows):

```bash
git clone https://github.com/AchGerGov/Bin_ch.git
cd Bin_ch
```

## Запуск

Проект не требует установки зависимостей или сборки — достаточно запустить скрипт напрямую.

### Linux / macOS

1. Откройте терминал и перейдите в папку проекта.
2. Сделайте скрипт исполняемым (опционально):

   ```bash
   chmod +x BinCode.py
   ```

3. Запустите:

   ```bash
   python3 BinCode.py
   ```

   Если в системе только `python` (Python 2), используйте `python3`.

### Windows

1. Откройте командную строку (`cmd`) или PowerShell.
2. Перейдите в папку проекта:

   ```cmd
   cd путь\к\Bin_ch
   ```

3. Запустите:

   ```cmd
   python BinCode.py
   ```

   Если команда `python` не найдена, попробуйте:

   ```cmd
   py BinCode.py
   ```
